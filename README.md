Livro de Receitas

Descrição

O Livro de Receitas é uma aplicação desktop desenvolvida em Java, destinada à organização e à consulta de receitas culinárias. O sistema foi pensado para reunir diferentes preparos em um único ambiente, distribuídos em categorias que facilitam a navegação e o acesso aos conteúdos.

A aplicação conta com uma tela inicial, a partir da qual o usuário pode acessar as categorias disponíveis, como bolos e pudins. A interface foi desenvolvida com o objetivo de proporcionar uma navegação simples e uma apresentação visual organizada, mantendo a proposta de um livro físico de receitas, mas incorporando os recursos de um ambiente digital.

Implementação

O desenvolvimento foi realizado em Java, utilizando a biblioteca Swing para a construção dos componentes gráficos e o NetBeans IDE como ambiente de programação. A estrutura do sistema foi dividida em classes destinadas à composição das interfaces e ao controle das ações realizadas pelo usuário.

A navegação entre as telas ocorre por meio de botões associados a eventos, que acionam os métodos responsáveis pela abertura dos respectivos painéis. Na organização do código, foram aplicados conceitos de programação orientada a objetos, buscando manter separadas a apresentação visual e a lógica de navegação.

Tecnologias

Java | Java Swing | NetBeans IDE
